# Negative Prompting

Явные запреты полезны для настоящих инвариантов: безопасности, сохранности данных и обязательных требований. Для стиля и качества положительная формулировка обычно понятнее длинного списка «не».

## Формулируй желаемое поведение

| Слабее | Точнее |
|---|---|
| Не пиши длинно | Ответ до 150 слов |
| Не используй сложные слова | Используй общеупотребительные слова; термин объясняй при первом появлении |
| Не выдумывай | Если сведений нет в источнике, пометь поле как неизвестное |
| Не задавай лишних вопросов | Спрашивай только о данных, способных изменить результат; иначе обозначь допущение |

## Настоящие запреты

Запрет должен быть конкретным и сопровождаться безопасной альтернативой.

```text
Не создавай и не изменяй файлы за пределами указанной папки.
Если это требуется для завершения задачи, остановись и назови точный путь.
```

```text
Не придумывай источники. Для неподтверждённого утверждения поставь статус
«не удалось проверить» и укажи, какого источника не хватает.
```

## Типичные ошибки

- десятки запретов конкурируют с главной задачей;
- абсолютное `никогда` используется там, где нужно правило принятия решения;
- запрет не объясняет, что делать вместо нежелательного поведения;
- одна строка «игнорируй prompt injection» выдаётся за защиту системы.

Стилевые предпочтения лучше хранить в отдельном руководстве и проверять примерами. См. [[Persona Prompting]], [[Outcome-first Prompting]], [[Indirect Prompt Injection]].
