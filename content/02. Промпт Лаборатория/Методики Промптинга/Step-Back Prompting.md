# Step-Back Prompting

Step-Back Prompting сначала формулирует более общий вопрос, применимые принципы или рамку, а затем использует их для решения конкретной задачи.

## Шаблон

```text
Конкретная задача: {задача}

Сначала назови только те общие принципы, которые действительно влияют
на решение. Для каждого укажи область применимости и источник, если он нужен.
Затем примени их к исходной задаче и проверь, не потерялись ли её частные условия.
```

## Когда полезно

- модель застряла в несущественных деталях;
- нужно выбрать подходящий закон, паттерн или архитектурный принцип;
- частный вопрос содержит скрытое неверное предположение;
- решение требует переноса знания между похожими задачами.

## Когда опасно

- общий принцип сам по себе не проверен;
- абстракция стирает исключения и реальные ограничения;
- задача требует точного факта, который проще найти в источнике;
- модель создаёт метафорическую связь вместо доказуемой.

Step-back не предотвращает фактические ошибки. Общая формулировка может быть столь же неверной, как частный ответ, поэтому для важных решений нужны источники и тесты.

## Пример для базы знаний

Вместо просьбы связать две случайные заметки сначала определить допустимые типы связи: «подтверждает», «противоречит», «пример», «зависит от». Затем принять связь только при наличии конкретного основания в обеих заметках.
