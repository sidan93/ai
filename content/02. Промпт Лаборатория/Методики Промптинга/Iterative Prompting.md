# Iterative Prompting (Итеративное улучшение)

Итеративное улучшение промпта — цикл «наблюдать ошибку → изменить инструкцию → проверить весь набор». Его цель — исправить конкретный класс сбоев без ухудшения остальных сценариев.

Полный цикл, baseline, пример с выдуманными ссылками и карточка эксперимента теперь собраны в [[Тестирование промптов|Тестировании и улучшении промптов]].
