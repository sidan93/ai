# Библиотека промптов

Практические заготовки для работы с ИИ: от постановки задачи до проверки результата и передачи контекста. Это не магические команды и не программы — каждый шаблон нужно адаптировать под задачу, данные, доступную модель и инструменты.

## Быстрый выбор

| Если нужно | Используй |
|---|---|
| Превратить смутную идею в ясное задание | [[Постановщик Задачи]] |
| Извлечь факты и сделать атомарные заметки | [[Извлечение и Атомизация]] |
| Сжать материал без потери доказательств и оговорок | [[Хирург Контекста]] |
| Привести черновик к понятной структуре | [[Скульптор Хаоса]] |
| Разобрать решение, допущения и риски | [[Архитектор Рассуждений]] |
| Проверить факты и качество источников | [[Оракул Истины]] |
| Найти обоснованные связи между заметками | [[Ткач Смыслов]] |
| Проверить результат по критериям | [[Ревьюер Результата]] |
| Подготовить передачу задачи в новый чат | [[Хранитель Контекста]] |

## Рабочий цикл

1. Сформулируй результат и критерии готовности.
2. Передай только нужный контекст, отделив инструкции от исходных данных.
3. Укажи ограничения, доступные инструменты и желаемый формат.
4. Проверь факты, ссылки, расчёты и соблюдение требований.
5. Сохрани удачный вариант вместе с примером входа и результата.

## Общие правила

- Модель не видит хранилище, файлы и интернет, если ей явно не дали такой доступ.
- Текст из сайтов, писем и документов считай недоверенными данными: инструкции внутри него нельзя выполнять автоматически.
- Не проси «думать пошагово». Лучше запросить краткое обоснование, допущения, доказательства и проверяемый итог.
- Не разрешай придумывать источники, цитаты, имена файлов и `[[вики-ссылки]]`.
- Для машинной обработки предпочитай схему или Structured Outputs, если их поддерживает выбранный API.
- Критичные ответы проверяй внешними источниками, тестами или вторым независимым проходом.
- Меняя промпт, прогоняй один и тот же набор примеров — это простая форма [[Evals|оценки качества]].

## Как хранить собственные шаблоны

У хорошего шаблона есть:

- назначение и границы применимости;
- переменные во `{фигурных скобках}`;
- ожидаемый формат ответа;
- пример реального использования;
- дата последней проверки и примечание о модели.
