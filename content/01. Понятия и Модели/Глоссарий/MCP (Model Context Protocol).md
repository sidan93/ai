# MCP (Model Context Protocol)

> [!abstract] Определение
> **MCP (Model Context Protocol)** — это открытый стандарт, разработанный для того, чтобы ИИ-модели могли бесшовно и безопасно подключаться к внешним источникам данных и инструментам. В 2026 году он стал "универсальным USB-портом" для нейросетей.

---

## 🧩 Как это работает (Простыми словами)
Раньше для каждой программы (Google Drive, Slack, Notion и др.) нужно было писать свой сложный код интеграции. MCP меняет правила: разработчик один раз создает **MCP-сервер**, и любая модель, поддерживающая протокол, мгновенно получает доступ к этим данным.

### Основные роли:
1. **Host (Хост):** Программа, через которую ты общаешься с ИИ (например, **Claude Desktop**, **Cursor** или **Ollama**).
2. **Client (Клиент):** Компонент внутри Хоста, который "разговаривает" с сервером.
3. **Server (Сервер):** Маленькая программа-коннектор, которая дает доступ к конкретному ресурсу (твоим файлам, календарю или поиску в Google).

---

## 💡 Почему это важно на практике?
До появления MCP нейросеть была "заперта" в окне чата. С MCP она получает **прямой доступ к твоему Vault**:
- Может читать твои заметки для контекста.
- Может создавать новые файлы по твоей просьбе.
- Может искать связи между заметками, используя свои вычислительные мощности.

## 🛡️ Безопасность
MCP разработан с учетом приватности. Хост (ИИ) не получает полного контроля над компьютером — он видит только те данные и инструменты, которые ты явно разрешил через конкретный MCP-сервер.
