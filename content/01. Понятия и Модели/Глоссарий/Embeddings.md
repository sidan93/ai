# Embeddings (Векторные представления)

> [!abstract] Определение
> **Embedding** — числовой вектор, который модель строит для текста, изображения или другого объекта так, чтобы полезные для обучения отношения можно было сравнивать математически.

## Как используют

Для семантического поиска embedding запроса сравнивают с embeddings документов, например по cosine similarity. Близость означает сходство в пространстве конкретной модели, но не гарантирует одинаковый смысл или правильность результата.

## Практика для базы знаний

1. Разбить документы на фрагменты.
2. Получить embedding каждого фрагмента одной моделью.
3. Сохранить векторы вместе с текстом и метаданными.
4. Для запроса найти ближайших кандидатов.
5. При необходимости выполнить фильтрацию и reranking.

Embeddings — популярный, но не обязательный компонент [[RAG (Retrieval-Augmented Generation)|RAG]]. Полнотекстовый и гибридный поиск иногда работают лучше, особенно для имён, кодов и точных фраз.

## Ограничения

- embeddings разных моделей обычно нельзя сравнивать напрямую;
- смена модели требует переиндексации;
- качество зависит от языка, домена, chunking и метрики;
- вектор может сохранять чувствительную информацию, поэтому индекс тоже нужно защищать.
