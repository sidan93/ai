# 🧭 Для начинающих: три шага к работе с ИИ

> [!abstract]
> Не нужно проходить курсы, выстраивать пайплайны и писать навыки, чтобы начать. Весь старт — это три шага: понять, с чем имеешь дело, открыть Claude Code и начать делать реальные задачи. Всё остальное придёт по ходу.

## 1) Понять, что это такое

LLM — это не «искусственный разум», а модель, которая продолжает текст. Отсюда её сила и её слабости. Без этого понимания любой уверенный ответ в чате будет казаться умнее, чем он есть.

- Прочитай [[Token|Токены]] и [[Hallucination|Галлюцинации]].
- Зафиксируй главное правило: **уверенный ответ модели ≠ истинный ответ**. Факты проверяем.
- Какие модели вообще есть и чем отличаются — [[Справочник основных LLM]].

---

## 2) Открыть Claude Code

Основной инструмент — `Claude Code`: терминальный агент, который работает прямо с твоими файлами и проектами. Это база, её достаточно для 95% задач. Технически это [[Harness|харнес]] — обвязка вокруг модели, которая даёт ей доступ к файлам, командам и памяти.

- Установка и первая сессия за 10 минут: [[Быстрый старт Claude Code]].
- Навигация по всему разделу: [[_Claude Code Index|Claude Code: мастер-индекс]].

Альтернативы (`Cursor`, `Antigravity` и прочие IDE-обвязки) — это уже для гиков и специфичных сценариев. Начинать с них не нужно.

---

## 3) Просто начать делать

Не учись «работать с ИИ» абстрактно — возьми реальную задачу и сделай её вместе с агентом.

- Начни с маленького и проверяемого: разобрать заметку, навести порядок в папке, поправить скрипт.
- Формулируй задачу в 1–2 предложениях с конкретным результатом.
- Проверяй итог сам: результат агента — черновик, пока ты его не принял.

Промпты, навыки, автоматизация и агентные системы — всё это подтянется само, когда упрёшься в реальную потребность. Если захочется глубже: [[_Prompt Lab Index|Prompt Lab]] и [[_Agentic Systems Index|Агентные системы]].
