# 🛠️ Фреймворки для создания ИИ-агентов

> [!abstract] Краткий обзор
> В 2026 году выбор фреймворка определяет не просто синтаксис, а архитектурную философию системы: будет ли это жесткая цепочка действий, автономная команда «сотрудников» или умный поиск по документам.

---

## 📊 Сравнение ключевых игроков

| Фреймворк | Основная специализация | Главная "суперсила" | Подходит для... |
| :--- | :--- | :--- | :--- |
| **[[LangChain]]** | Универсальный конструктор | Огромная экосистема и интеграции | Enterprise-систем и сложных графов |
| **[[LlamaIndex]]** | Работа с данными (RAG) | Умная индексация и поиск | Корпоративных баз знаний |
| **[[CrewAI]]** | Командная работа (Multi-agent) | Ролевая модель и делегирование | Автоматизации бизнес-процессов |
| **[[AutoGen]]** | Диалоги и Код | Автономное исполнение и отладка кода | Программирования и тех. задач |
| **[[Haystack]]** | NLP Пайплайны | Прозрачность и модульность графов | Высоконагруженного поиска |

---

## 🗺️ Навигатор по папке

### 🦜 [[LangChain]]
Швейцарский нож индустрии. Используй его, если нужна максимальная гибкость и продвинутый мониторинг через LangSmith. Включает **LangGraph** для циклической логики.

### 🦙 [[LlamaIndex]]
Если данные — это сердце твоего проекта. Лучший выбор для тех, кто строит "второй мозг" или систему, которая должна идеально знать тысячи документов.

### 👥 [[CrewAI]]
Фреймворк для управления "отделами". Позволяет нанимать виртуальных аналитиков, копирайтеров и менеджеров, которые работают сообща.

### 🤖 [[AutoGen]]
Лучший выбор для тех, кто хочет, чтобы ИИ писал софт. Агенты сами запускают код, видят ошибки и исправляют их в бесконечном цикле до победного конца.

### 🌾 [[Haystack]]
Строгий и надежный инструмент для тех, кто ценит чистоту архитектуры. Идеально подходит для создания стабильных поисковых систем в больших компаниях.

---

## 📈 Критерии выбора (Cheat Sheet)

* **Нужен поиск по PDF?** → Тебе в [[LlamaIndex]].
* **Нужна команда из 5 агентов?** → Смотри [[CrewAI]].
* **Нужно, чтобы агент писал код на Python?** → Бери [[AutoGen]].
* **Нужна сложная логика с ветвлениями?** → Используй [[LangChain]].
* **Нужен надежный поиск для продакшена?** → Выбирай [[Haystack]].
