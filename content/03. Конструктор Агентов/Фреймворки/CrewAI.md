# CrewAI

> [!abstract] Суть
> CrewAI — opinionated framework для агентной автоматизации. **Crews** моделируют совместную работу ролевых агентов, а **Flows** задают событийную оркестрацию, состояние и контроль процесса.

## Два уровня

| Уровень | Для чего |
| :--- | :--- |
| Agent | Роль, цель, модель, контекст и tools |
| Task | Поручение, ожидаемый результат и исполнитель |
| Crew | Команда агентов и порядок их совместной работы |
| Flow | Stateful workflow: события, ветвления, persistence и вызовы crews |

Crew и Flow решают разные задачи. Если процесс должен строго следовать правилам, его каркас лучше выразить Flow, а агентность оставить только там, где решение нельзя надёжно закодировать.

## Когда выбирать

- предметная область естественно раскладывается на роли с разными инструментами и контекстом;
- важна быстрая сборка crew-based эксперимента;
- нужен единый проект, где детерминированный Flow вызывает отдельные crews.

Не используй несколько агентов как замену хорошей декомпозиции. Каждый дополнительный агент увеличивает стоимость, latency, объём контекста и поверхность ошибок.

## Как доказать пользу crew

Сравни на одном наборе evals:

1. один агент со всеми необходимыми tools;
2. детерминированный workflow с одним-двумя LLM-шагами;
3. crew с разделением ролей.

Измеряй не только итоговое качество, но и стабильность, число вызовов, стоимость, время, воспроизводимость и сложность разбора ошибок.

## Production-чек

- лимиты итераций, времени и бюджета;
- минимальные права tools и approvals перед внешними действиями;
- persistence, resumability и идемпотентность;
- tracing каждого task/tool handoff;
- схемы и валидация промежуточных результатов;
- pinned versions и проверка migration notes.
