# 🛠 Библиотека инструментов (Tooling Matrix)

> [!abstract] Назначение
> Это реестр доступных ИИ-агенту технических мощностей (MCP-серверов). Файл служит справочником для формирования разделов `Tools` в конфигурациях `.cursorrules` и `CLAUDE.md`.

## 🧬 Синергия инструментов (Комбо)

Эффективные навыки часто требуют одновременного использования нескольких серверов. Примеры связок для прописывания в `Guidelines`:

### 🔍 Комплексный ресерч
- **Связка:** `Brave Search` + `Puppeteer` + `Filesystem`.
- **Логика:** Найти ссылку -> Извлечь контент -> Сохранить в базу.

### 🧠 Глубокая разработка
- **Связка:** `Sequential Thinking` + `Filesystem` + `Linter/Compiler`.
- **Логика:** Продумать шаги -> Изменить код -> Проверить ошибки.

### 📅 Автоматизация лайфстайла
- **Связка:** `Google Calendar` + `Gmail` + `Memory`.
- **Логика:** Проверить почту -> Найти свободное окно -> Записать встречу, учитывая предпочтения.

---

## ⚙️ Инструкция по обновлению

Когда ты добавляешь новый MCP-сервер в свою систему:
1. Создай техническое описание в папке `Model Context Protocol`.
2. Добавь строку в таблицу выше.
3. Опиши новый **Навык**, который этот инструмент делает возможным, в папке `Examples`.

---

## 🛡️ Безопасность и Лимиты

- **Read-Only:** Для критических папок используй инструмент в режиме чтения.
- **Token Usage:** Помни, что `Puppeteer` и `Search` потребляют больше контекстного окна.
- **Confirmation:** Для инструментов действия (Calendar, Shell) всегда требуй подтверждения (`user_approval: true`).
