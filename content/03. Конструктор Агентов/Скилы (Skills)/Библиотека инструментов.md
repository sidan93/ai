## 🧬 Синергия инструментов (Комбо)

Некоторые процессы используют несколько инструментов. Это примеры архитектуры, а не готовые конфигурации:

### 🔍 Комплексный ресерч
- **Связка:** `Brave Search` + `Puppeteer` + `Filesystem`.
- **Логика:** Найти ссылку -> Извлечь контент -> Сохранить в базу.

### 🧠 Глубокая разработка
- **Связка:** `Sequential Thinking` + `Filesystem` + `Linter/Compiler`.
- **Логика:** Продумать шаги -> Изменить код -> Проверить ошибки.

### 📅 Работа с расписанием
- **Связка:** календарь + источник запроса + хранилище настроек.
- **Логика:** прочитать запрос -> предложить свободное окно -> получить подтверждение -> создать встречу.

## ⚙️ Инструкция по обновлению

Когда ты добавляешь новый MCP-сервер в свою систему:
1. Создай техническое описание в папке `Model Context Protocol`.
2. Добавь строку в таблицу выше.
3. Проверь издателя, разрешения, область доступа и сценарий отзыва токена.
4. Если инструмент нужен навыку, опиши зависимость и безопасный тест в заметке навыка.

---

## 🛡️ Безопасность и Лимиты

- **Read-Only:** Для критических папок используй инструмент в режиме чтения.
- **Token Usage:** Помни, что `Puppeteer` и `Search` потребляют больше контекстного окна.
- **Confirmation:** Для необратимых или внешних действий требуй подтверждение способом, который действительно поддерживает выбранная среда; имя настройки не универсально.
