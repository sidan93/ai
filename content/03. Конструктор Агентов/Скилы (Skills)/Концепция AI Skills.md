# AI Skills

> [!abstract] Определение
> Skill — повторно используемая операционная процедура для агента. Обычно она включает условия применения, инструкции, ресурсы, зависимости, ограничения и способ проверить результат.

## Простая модель

```text
Модель умеет рассуждать
Tool позволяет выполнить действие
MCP доставляет capabilities
Skill объясняет рабочий процесс
Agent управляет циклом выполнения
Harness задаёт среду, права и контекст
```

## Не путать

| Понятие | Что это | Пример |
| :--- | :--- | :--- |
| Prompt | один запрос или шаблон запроса | «сделай ревью этого diff» |
| Project instructions | постоянные правила рабочей области | стиль кода, обязательные тесты |
| Tool | вызываемая операция | прочитать файл, выполнить SQL |
| MCP server | протоколируемый поставщик tools, resources и prompts | Filesystem MCP |
| Skill | процедура для класса задач | провести безопасное code review |
| Plugin | распространяемый пакет возможностей конкретной платформы | skills + MCP + UI |
| Agent | runtime-цикл выбора и проверки действий | coding agent |

Skill может быть полностью текстовым. Он также может вызывать scripts, tools или MCP-серверы, но сам по себе не выдаёт новых системных прав.

## Два значения слова Skills

### Файловый skill

Папка с `SKILL.md` и необязательными ресурсами. Клиент обнаруживает описание, решает, подходит ли навык, а затем читает нужные инструкции и файлы. Точная схема и каталоги зависят от клиента.

### Hosted/API skill

Управляемый ресурс платформы. В OpenAI API skill можно загрузить как набор файлов или ZIP, получать его содержимое, создавать неизменяемые версии и выбирать default version. Такой ресурс можно подключать к hosted agent environment.

Это способы доставки одной идеи, но их установка, версия и доступность различаются. Не переноси команды настройки между ними вслепую.

## Что делает навык качественным

1. Узкая и наблюдаемая цель.
2. Точные положительные и отрицательные триггеры.
3. Минимальный обязательный контекст.
4. Последовательность действий с точками проверки.
5. Явные права и условия подтверждения.
6. Детерминированные scripts для механических операций.
7. Проверяемый Definition of Done.
8. Понятный fallback при отсутствии зависимости.

## Progressive disclosure

Хороший пакет не загружает весь справочник сразу:

1. **Метаданные** помогают обнаружить подходящий навык.
2. **Основная инструкция** задаёт маршрут.
3. **References и assets** читаются только для конкретной ветки задачи.
4. **Scripts** выполняют повторяемые и проверяемые преобразования.

Это снижает расход контекста и вероятность конфликта между лишними инструкциями.

## Ограничения

- Skill не гарантирует, что модель выберет его в каждой подходящей ситуации.
- Длинная инструкция не компенсирует отсутствующий tool или доступ.
- Текстовая проверка «убедись, что всё хорошо» слабее реального теста.
- Несколько пересекающихся skills могут конкурировать по описаниям и правилам.
- Недоверенный skill способен влиять на поведение агента и запускать scripts в пределах выданных прав.
