# AI Skills (Навыки агента)

> [!abstract] Определение
> Skill — повторно используемая процедура для агента: инструкции, условия применения, необходимые инструменты, ресурсы и критерии проверки результата. Конкретный формат зависит от платформы.

## Не путать

| Понятие | Роль |
| :--- | :--- |
| Prompt | Один запрос или шаблон текста |
| Project rules | Постоянные правила репозитория или рабочей области |
| Tool | Функция, которую система может выполнить |
| MCP server | Способ предоставить tools, resources или prompts приложению |
| Skill | Операционная процедура, которая может использовать инструкции, tools и ресурсы |
| Agent | Runtime-цикл, выбирающий действия для достижения цели |

Skill не обязан иметь MCP-инструмент. И наоборот, наличие tool не объясняет агенту, когда и как его безопасно применять.

## Хороший навык содержит

1. Ясную цель и триггеры применения.
2. Границы: когда навык не использовать.
3. Необходимый контекст и входные данные.
4. Пошаговую процедуру.
5. Правила выбора инструментов.
6. Ограничения и подтверждения.
7. Проверяемый Definition of Done.
8. Обработку ошибок и запасной путь.
9. Примеры только там, где они снимают неоднозначность.

## Уровни

- **Инструкция:** преобразование или анализ без внешних действий.
- **Инструментальный навык:** использует один или несколько tools.
- **Workflow-навык:** координирует последовательность проверяемых шагов.
- **Доменный навык:** содержит специализированные правила, справочники и шаблоны.

Не стоит называть «когнитивным инструментом» всё, что предлагает модели думать пошагово. Лучше описывать наблюдаемую процедуру и проверку результата.

## Жизненный цикл

1. Создать минимальную версию.
2. Проверить на типичных и пограничных примерах.
3. Зафиксировать провалы.
4. Уточнить инструкции или добавить детерминированную проверку.
5. Версионировать изменения.
6. Периодически перепроверять зависимости и API.
