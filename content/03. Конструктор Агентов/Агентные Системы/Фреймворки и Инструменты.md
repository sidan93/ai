# 🛠️ Фреймворки и Инструменты

> [!quote] Состояние рынка
> В 2026 году разработка агентов разделилась на два лагеря: **Low-code** (быстрая сборка в GUI) и **Pro-code** (сложное дирижирование через код). Главный тренд — нативная поддержка локальных моделей через [[Ollama]].

---

## 🏗️ 1. Топ фреймворков для разработки (Pro-code)

| Фреймворк | Сильная сторона | Для чего лучше всего? |
| :--- | :--- | :--- |
| **LangGraph** | Циклические графы | Самые надежные и предсказуемые агенты со сложной логикой. |
| **CrewAI** | Ролевая модель | Сборка "отдела" из разных агентов (Исследователь + Писатель). |
| **AutoGen 2.0** | Динамический диалог | Агенты, которые решают задачи в процессе свободного общения. |
| **PydanticAI** | Типизация и надежность | Современный стандарт для интеграции агентов в Production. |

---

## 🧩 2. No-code / Low-code платформы (Quick Start)

* **n8n (Agentic Nodes):** Самый мощный инструмент для автоматизации. Позволяет визуально соединить Telegram, Google Drive и LLM в одну цепочку.
* **Dify / Flowise:** Визуальные конструкторы промптов и RAG-систем. Идеально для тех, кто не хочет писать код на Python.
* **Open WebUI:** Лучший интерфейс для работы с [[Ollama]], поддерживающий "Functions" (агентные навыки) прямо в чате.

---

## 🖥️ 3. Агентные CLI (Инструментарий 2026)

* **Claude Code:** Прорыв года. Агент, который живет в терминале, имеет доступ к файлам и сам фиксит баги.
* **Aider:** Классика, которая в 2026 году стала стандартом для парного программирования с ИИ.
* **Open Interpreter:** Агент, который управляет твоим компьютером (двигает мышкой, открывает браузер), исполняя команды на языке естественной речи.

---

## 📦 4. Вспомогательные инструменты

- **Tavily / Exa:** Поисковые движки, оптимизированные для агентов (выдают чистый контент без рекламы).
- **LangSmith:** Инструмент для "прослушки" агента — позволяет увидеть, где именно в логической цепочке он совершил ошибку.
- **Mem0:** Система самообучающейся долгосрочной памяти для персональных ассистентов.

---

## 💡 Совет по выбору
Если ты только начинаешь, начни с **n8n** или **Open WebUI**. Они позволяют почувствовать "агентность" без написания сотен строк кода. Если хочешь создавать профессиональные системы — изучай **LangGraph**.
