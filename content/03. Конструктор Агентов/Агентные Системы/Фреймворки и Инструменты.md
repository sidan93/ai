# Инструменты агентной системы

Эта заметка разделяет роли компонентов. Сравнение конкретных фреймворков находится в [[_Frameworks Index]].

| Категория | Что решает | Примеры |
| :--- | :--- | :--- |
| Model SDK | Вызов модели и tools | SDK провайдера |
| Оркестрация | Циклы, графы и состояние | LangGraph, AutoGen Core, CrewAI Flows |
| Retrieval | Ingestion, поиск и контекст | LlamaIndex, Haystack, собственный pipeline |
| Observability | Трейсы, метрики и датасеты | LangSmith и другие tracing/eval-платформы |
| Runtime кода | Изолированное выполнение | контейнер, sandbox, удалённый executor |
| Интеграции | Внешние данные и действия | API, [[MCP (Model Context Protocol)]] |
| Интерфейс | Работа пользователя | CLI, IDE, web UI, мессенджер |

## Правило выбора

Добавляй компонент только если он решает наблюдаемую проблему. Каждый новый слой увеличивает число зависимостей, поверхность атаки и сложность отладки.
