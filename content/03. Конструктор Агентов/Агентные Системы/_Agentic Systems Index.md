# Агентные системы

Агентная система — это модель внутри программного контура, которая получает цель, выбирает допустимые действия, использует инструменты, наблюдает результат и продолжает до достижения критерия готовности или условия остановки.

Автономность не является магическим свойством модели. Её определяют выданные права, среда выполнения, правила подтверждения и код оркестратора.

## Сначала простой контур

Начинай с одного вызова модели или детерминированного workflow. Добавляй agent loop только если задача действительно требует динамического выбора следующих действий. Несколько агентов оправданы, когда есть независимый параллелизм, различные полномочия или изолированный контекст — сами по себе роли качество не гарантируют.

## Минимальная схема

```text
цель + критерии
      ↓
модель выбирает ответ или допустимый tool call
      ↓
оркестратор проверяет права и выполняет действие
      ↓
результат записывается в состояние и trace
      ↓
проверка: готово / продолжить / запросить подтверждение / остановиться
```
