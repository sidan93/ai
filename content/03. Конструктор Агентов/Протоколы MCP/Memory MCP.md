# 🧠 Memory MCP

> [!abstract] Роль: "Цифровой гиппокамп"
> **Memory MCP** — это сервер, который позволяет модели создавать и хранить долгосрочные воспоминания в виде графа знаний. Он извлекает сущности и связи из ваших разговоров, позволяя ИИ "помнить" контекст даже спустя месяцы после того, как он выпал из окна текущего чата.

---

## ⚡ Главные суперсилы

1. **Извлечение сущностей (Entity Extraction):** Модель автоматически понимает, что "Проект Орион" или "мой кот Барсик" — это важные объекты, о которых нужно помнить.
2. **Хранение предпочтений:** ИИ запоминает твой стиль письма и то, как ты предпочитаешь структурировать свои мысли.
3. **Графовая структура:** Память хранится не просто списком, а сетью взаимосвязей (например: "Иван" -> "автор проекта" -> "AI Lab").
4. **Контекстный поиск:** Перед ответом модель быстро сканирует свою "память", чтобы найти факты, которые могут быть полезны в текущем вопросе.

---

## 🎯 Применение на практике

### 👤 Персонализация "Второго мозга"
*"Помни, что когда я пишу заметки по коду, я всегда использую Callout типа [!code]."* Теперь ИИ будет делать это автоматически, не требуя напоминаний в каждом промпте.

### 📅 Хронология идей
*"Вспомни, что мы обсуждали месяц назад касательно стратегии развития этой базы знаний".* Модель достанет из памяти тезисы, даже если лог того чата уже удален.

### 🕵️ Поиск противоречий
Благодаря долгосрочной памяти, ИИ может заметить: *"Кстати, сегодня ты написал, что предпочитаешь локальные модели, но две недели назад ты говорил, что облачные API для тебя приоритетнее. Что изменилось?"*.

## ⚙️ Настройка (Конфиг 2026)

Для подключения официального сервера памяти (обычно на базе JSON или векторной БД), добавь этот блок в `mcp_config.json`:

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-memory"
      ]
    }
  }
}
