# Memory MCP

Memory-сервер хранит данные между сессиями и предоставляет операции добавления, поиска, изменения или удаления записей. Это внешнее состояние агента, а не «память модели».

## Что определить заранее

- какие данные разрешено сохранять;
- кто и когда создаёт запись;
- срок хранения;
- способ исправления и удаления;
- область памяти: пользователь, проект или организация;
- может ли модель увидеть источник и дату записи.

## Риски

- сохранение неверного вывода как факта;
- накопление чувствительных данных;
- prompt injection в сохранённых записях;
- смешение данных разных пользователей;
- устаревшие предпочтения без даты и происхождения.

Хорошая запись памяти содержит значение, источник, дату, область применимости и уровень уверенности. Важные факты пользователь должен иметь возможность просмотреть и исправить.

Актуальную реализацию выбирай через [MCP Registry](https://registry.modelcontextprotocol.io/) после проверки кода, хранения и политики доступа.
