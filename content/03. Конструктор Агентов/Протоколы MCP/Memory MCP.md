# Memory MCP

Memory reference server хранит простой knowledge graph из сущностей, наблюдений и связей. Это демонстрация долговременного состояния через MCP, а не готовая универсальная память агента.

Официальный reference package — `@modelcontextprotocol/server-memory`. Перед использованием проверь текущую реализацию, формат файла и гарантии сохранности.

## Что определить заранее

- какие классы данных разрешено сохранять;
- кто является владельцем записи;
- откуда взялось утверждение и кем оно подтверждено;
- область: пользователь, проект или организация;
- срок хранения и правила устаревания;
- просмотр, исправление, экспорт и удаление;
- резервное копирование и восстановление после повреждения.

## Риски

- гипотеза модели сохраняется как факт;
- данные разных пользователей смешиваются;
- секрет или чувствительная информация записывается навсегда;
- prompt injection возвращается из памяти в будущую сессию;
- дубли и противоречия накапливаются без консолидации;
- процесс прерывается во время записи и повреждает единственное хранилище.

## Хорошая запись

```yaml
value: "Предпочитает краткие ответы"
kind: user_preference
source: explicit_user_statement
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
scope: user-id
confidence: confirmed
expires_at: null
```

## Проверка

1. Записать тестовый факт с provenance.
2. Найти его только в правильной области пользователя.
3. Исправить и удалить через доступный интерфейс.
4. Передать противоречащую запись и проверить разрешение конфликта.
5. Смоделировать перезапуск и повреждённое хранилище.
6. Убедиться, что секреты и инструкции атаки не возвращаются модели.
