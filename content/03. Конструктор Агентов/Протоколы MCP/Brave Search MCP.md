# Brave Search MCP

Подключает поисковый API Brave к MCP-host. Полезен для поиска актуальных страниц, но сам по себе не выполняет фактчекинг: модель должна открыть источники, сопоставить утверждения и сослаться на них.

## Перед установкой

- найди актуальный сервер в [MCP Registry](https://registry.modelcontextprotocol.io/);
- проверь издателя, репозиторий, лицензию и дату релиза;
- изучи тариф и retention Brave Search API;
- храни API-ключ в secret/env, а не в заметке или репозитории;
- ограничь число запросов и размер возвращаемого текста.

## Проверка

1. Выполни простой запрос с однозначным результатом.
2. Убедись, что ответ содержит URL и заголовки.
3. Проверь обработку ошибки API и исчерпания квоты.
4. Протестируй вредоносную инструкцию внутри найденной страницы.
5. Убедись, что модель не выдаёт snippet за прочитанный первоисточник.
