# 🔍 Brave Search MCP

> [!abstract] Роль: "Глаза ИИ"
> **Brave Search MCP** — это официальный коннектор, который позволяет модели выходить в "живой" интернет. Он решает главную проблему LLM — ограничение датой обучения (Knowledge Cutoff).

---

## ⚡ Главные суперсилы

1. **Актуальность:** Модель может узнать курс акций, погоду или вчерашний релиз новой библиотеки.
2. **Фактчекинг:** Автоматическая проверка утверждений через поиск в авторитетных источниках.
3. **Обход "галлюцинаций":** Если модель не уверена в факте, она обязана сначала "погуглить".
4. **Поиск по документации:** Мгновенный доступ к самым свежим мануалам API, которые вышли после обучения модели.

---

## 🎯 Применение на практике

### 📑 Обогащение заметок
Ты пишешь заметку про новую модель ИИ. Модель через Brave Search сама находит её параметры, цену за 1 млн токенов и ссылки на тесты, добавляя их в твой файл.

### 🛡️ Верификация знаний
Используй этот сервер вместе с промптом [[Оракул Истины]]. Модель будет задавать себе вопросы, проверять их в сети и исправлять ошибки в твоей базе.

## ⚙️ Настройка (Конфиг 2026)

Для работы сервера нужен **API Key** (получается на сайте Brave Search). Добавь этот блок в `mcp_config.json`:

```json
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-brave-search"
      ],
      "env": {
        "BRAVE_SEARCH_API_KEY": "ТВОЙ_КЛЮЧ_ЗДЕСЬ"
      }
    }
  }
}
