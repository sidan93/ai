# 📂 Мастер Файловой Системы

> [!abstract] Роль: "Руки ИИ"
> **Filesystem MCP** — это фундаментальный сервер, который дает модели возможность напрямую взаимодействовать с твоим локальным хранилищем. Благодаря ему ИИ перестает быть просто "чатом" и становится полноценным файловым менеджером.

---

## ⚡ Главные суперсилы

1. **Чтение (Read):** Модель может открывать любые твои заметки, PDF и логи для анализа.
2. **Запись (Write):** ИИ сам создает новые файлы или дополняет существующие (например, дописывает итоги дня в Daily Note).
3. **Поиск (Search):** Мгновенный поиск по всей глубине твоего Vault без необходимости индексации вручную.
4. **Управление (Manage):** Создание папок, перемещение заметок и наведение порядка в иерархии.

---

## 🎯 Применение на практике

### 🏗️ Авто-организация
Ты можешь дать команду: *"Просмотри мой Inbox, создай для каждой заметки подходящую папку по теме и разложи их туда"*.

### 🧩 Сборка проектов
*"Найди в базе все наброски по проекту 'Марс', объедини их в один структурированный черновик и сохрани в папку Projects"*.

### 🧹 Чистка базы
*"Найди пустые заметки или файлы без тегов и выведи мне список на удаление"*.

## ⚙️ Настройка (Конфиг 2026)

Для подключения в **Claude Desktop** или **Ollama**, добавь путь к твоему Vault в файл конфигурации (`mcp_config.json`):

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/имя/Documents/My_Knowledge_Base"
      ]
    }
  }
}
