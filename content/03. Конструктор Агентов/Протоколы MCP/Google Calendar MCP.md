# 📅 Google Calendar MCP

> [!abstract] Роль: "Менеджер расписания"
> **Google Calendar MCP** — это сервер, обеспечивающий двустороннюю связь между ИИ и твоим календарем. Он позволяет модели просматривать события, создавать новые встречи, редактировать существующие и находить свободные окна для работы прямо во время анализа твоих заметок.

---

## ⚡ Главные суперсилы

1. **Обзор дня:** Модель может мгновенно прочитать твое расписание на сегодня/неделю и сопоставить его со списком задач.
2. **Умное планирование:** ИИ сам находит свободные слоты для "Deep Work" на основе твоих биоритмов или дедлайнов, описанных в базе.
3. **Авто-создание событий:** Заметил в конспекте созвона фразу "надо встретиться через неделю"? Модель сама предложит создать событие.
4. **Синхронизация Daily Notes:** Автоматический перенос всех запланированных встреч из календаря в твою ежедневную заметку утром и запись итогов вечером.

---

## 🎯 Применение на практике

### 🏗️ Планирование из заметок
Ты ведешь проектную заметку. 
*"Проверь мои дедлайны по проекту 'Альфа' и забронируй в календаре по 2 часа каждое утро на этой неделе для работы над ним"*.

### 📝 Подготовка к встречам
*"Посмотри, с кем у меня сегодня встреча в 15:00, найди все последние заметки, связанные с этим человеком, и сделай мне краткий бриф"*.

### 🧹 Наведение порядка
*"Найди в календаре все повторяющиеся события, которые я игнорировал последние две недели, и предложи их удалить или перенести"*.

## ⚙️ Настройка (Конфиг 2026)

Для работы требуется настройка проекта в Google Cloud Console и получение OAuth-учетных данных. Добавь этот блок в `mcp_config.json`:

```json
{
  "mcpServers": {
    "google-calendar": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-google-calendar"
      ]
    }
  }
}
