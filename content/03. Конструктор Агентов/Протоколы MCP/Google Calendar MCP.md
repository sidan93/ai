# Google Calendar MCP

Интеграция календаря может читать события, искать свободное время и, при выданных правах, создавать или менять встречи. Конкретные возможности зависят от сервера.

## Рекомендуемая модель доступа

- чтение календаря разрешать отдельно от записи;
- создание события выполнять только после показа даты, часового пояса, календаря и участников;
- изменение и удаление существующих событий подтверждать отдельно;
- отправку приглашений считать внешним действием;
- начинать с отдельного тестового календаря и минимальных OAuth scopes.

## Перед установкой

Найди сервер в [MCP Registry](https://registry.modelcontextprotocol.io/), проверь издателя и документацию. Не устанавливай пакет только по совпадению имени. OAuth client secret и refresh token не должны попадать в vault.

## Проверка

1. Прочитать одно тестовое событие.
2. Правильно обработать часовой пояс и переход даты.
3. Создать черновик без приглашений.
4. Показать preview перед отправкой участникам.
5. Отозвать OAuth-доступ и убедиться, что сервер больше не работает.
