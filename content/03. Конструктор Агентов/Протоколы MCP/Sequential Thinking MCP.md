# Sequential Thinking MCP

Sequential Thinking reference server предоставляет внешний scratchpad для создания, пересмотра и ветвления последовательности шагов. Он демонстрирует tool-based процесс рассуждения, но не добавляет новых знаний и не гарантирует правильность.

Официальная reference-реализация публикуется как `@modelcontextprotocol/server-sequential-thinking`. Перед установкой сверяй актуальный package и repository.

## Когда может быть полезен

- нужно сохранять явный план между tool calls;
- задача имеет зависимые этапы и возможный re-plan;
- важно сравнить несколько ветвей решения;
- отладка требует увидеть, где изменилось допущение.

## Когда не нужен

- задача решается одним вызовом или детерминированным workflow;
- reasoning-модель уже стабильно выполняет её без внешнего scratchpad;
- подробный журнал создаёт больше шума, чем проверяемых артефактов;
- контекст содержит секреты или чувствительные рассуждения.

## Ограничения

- число шагов не связано напрямую с качеством;
- связная цепочка может начинаться с ложного допущения;
- инструмент увеличивает latency и размер контекста;
- scratchpad не заменяет checkpoint реального состояния;
- опубликованное объяснение не обязательно отражает внутреннее вычисление модели.

## Практическое применение

1. Сначала сформулировать outcome и критерии готовности.
2. Ограничить бюджет шагов и ветвей.
3. Записывать проверяемые факты отдельно от гипотез.
4. Сохранять результаты инструментов по точным идентификаторам.
5. Завершать конкретным решением, доказательствами и открытыми вопросами.
