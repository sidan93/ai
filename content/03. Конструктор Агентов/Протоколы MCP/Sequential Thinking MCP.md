# 🧠 Sequential Thinking MCP

> [!abstract] Роль: "Интеллектуальный процессор"
> **Sequential Thinking MCP** — это специализированный инструмент, который заставляет модель использовать структурированный процесс мышления. Он позволяет ИИ разбивать сложные проблемы на этапы, пересматривать свои выводы и исследовать альтернативные пути решения (ветвление), прежде чем выдать финальный результат.

---

## ⚡ Главные суперсилы

1. **Декомпозиция:** Принудительное разбиение одной огромной задачи на 10-20 мелких логических шагов.
2. **Самокоррекция:** Модель может вернуться на шаг назад, если поймет, что её предыдущее рассуждение было ошибочным.
3. **Ветвление (Branching):** Возможность рассмотреть сценарий "А" и сценарий "Б" параллельно, сравнив их эффективность.
4. **Прозрачность:** Ты видишь весь лог размышлений (Internal Monologue), что позволяет понять, *почему* ИИ пришел к такому выводу.

---

## 🎯 Применение на практике

### 🏗️ Проектирование сложных систем
Когда ты планируешь структуру нового раздела базы или архитектуру проекта. 
*"Используй Sequential Thinking, чтобы распланировать миграцию моих заметок на новую систему тегов. Учти риски потери связей".*

### 🧪 Глубокий анализ данных
*"Проанализируй все мои заметки по теме 'Биотехнологии' и выдели 3 главных противоречия в моих рассуждениях за последний год. Не торопись, продумай каждый аргумент".*

### 🖋️ Написание лонгридов
Модель сначала выстраивает логический скелет, проверяет его на прочность, "наращивает мясо" и только потом выдает готовый текст.

## ⚙️ Настройка (Конфиг 2026)

Этот сервер часто идет в комплекте с официальным набором от Anthropic. Добавь этот блок в `mcp_config.json`:

```json
{
  "mcpServers": {
    "sequential-thinking": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-sequential-thinking"
      ]
    }
  }
}
