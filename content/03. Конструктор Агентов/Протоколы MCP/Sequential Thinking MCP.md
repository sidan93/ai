# Sequential Thinking MCP

Инструмент предоставляет внешнюю структуру для разбиения задачи, пересмотра шагов и ветвления вариантов. Это scratchpad и протокол работы, а не дополнительный источник знаний.

## Когда полезен

- задача имеет несколько зависимых этапов;
- нужно сохранить явный план вне одного ответа;
- важно сравнить альтернативы;
- требуется зафиксировать изменения решения.

## Ограничения

- больше шагов не означает более правильный вывод;
- уверенная последовательность может строиться на неверном допущении;
- лог может быть длинным и содержать чувствительные данные;
- для простых задач инструмент добавляет задержку без пользы.

## Как применять

1. Сначала сформулировать проверяемую цель.
2. Ограничить число шагов или бюджет.
3. Отделить факты от предположений.
4. Для ключевых фактов использовать источник или tool.
5. Завершить кратким решением и независимой проверкой.

Актуальный сервер и способ установки ищи в [MCP Registry](https://registry.modelcontextprotocol.io/). Не считай пакет официальным только из-за названия.
