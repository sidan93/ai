# Browser automation MCP

MCP-сервер на базе Puppeteer или другого browser runtime может открывать страницы, взаимодействовать с интерфейсом, извлекать текст и делать скриншоты.

## Риски

Веб-страница является недоверенным вводом. Она может содержать prompt injection, скрытый текст, вредоносные загрузки и элементы, похожие на системные сообщения.

## Безопасная настройка

- отдельный профиль браузера без личных cookies;
- песочница и отдельная папка загрузок;
- allowlist доменов для чувствительных сценариев;
- запрет ввода паролей и платёжных данных моделью;
- preview перед отправкой форм, публикацией и покупкой;
- ограничение скачиваемых типов файлов;
- журнал URL, кликов и отправленных данных.

Автоматизация не должна обходить CAPTCHA, paywall, контроль доступа или условия использования сайта.

## Проверка

1. Открыть тестовую страницу и извлечь заголовок.
2. Обработать страницу с вредоносной инструкцией как данные.
3. Убедиться, что публикация формы требует подтверждения.
4. Проверить изоляцию cookies и загрузок.
5. Убедиться, что результат содержит исходный URL.

Сервер выбирай через [MCP Registry](https://registry.modelcontextprotocol.io/) и документацию host-приложения.
