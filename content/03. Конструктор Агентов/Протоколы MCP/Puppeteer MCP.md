# 🌐 Puppeteer MCP

> [!abstract] Роль: "Полноценный серфинг"
> **Puppeteer MCP** — это сервер автоматизации браузера (Chromium). Он позволяет модели не просто получать ссылки, а буквально "заходить" на сайты, нажимать на кнопки, делать скриншоты и извлекать чистый текст, скрытый за сложной версткой или скриптами.

---

## ⚡ Главные суперсилы

1. **Глубокий парсинг:** Извлечение контента с сайтов, которые не индексируются обычными поисковиками.
2. **AI-взаимодействие:** В 2026 году сервер умеет сам закрывать всплывающие окна, принимать cookie-соглашения и даже проходить простые капчи.
3. **Markdown-конвертация:** Автоматическое превращение "грязного" HTML кода страницы в чистый Markdown для заметок.
4. **Визуальный контроль:** Возможность попросить ИИ сделать скриншот страницы (или её части), чтобы убедиться, что информация верна.

---

## 🎯 Применение на практике

### 📚 Наполнение Zettelkasten
Ты даешь ссылку на сложную научную статью или пост в Substack. 
*"Используй Puppeteer, чтобы зайти по ссылке, убери рекламу и сохрани основной текст в новую заметку, сохранив все таблицы и списки"*.

### 🕵️‍♂️ Глубокий ресерч (Deep Research)
*"Найди на сайте конкурентов все упоминания их новой фичи, загляни в раздел 'Цены' и обнови мою сравнительную таблицу"*.

### 📸 Визуальный архив
Если ты ведешь базу знаний по дизайну или интерфейсам: *"Зайди на этот сайт и сделай скриншот первого экрана, сохрани его в папку 'Assets' и прикрепи к текущей заметке"*.

## ⚙️ Настройка (Конфиг 2026)

Для запуска требуется установленный Node.js. Добавь этот блок в твой `mcp_config.json`:

```json
{
  "mcpServers": {
    "puppeteer": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-puppeteer"
      ]
    }
  }
}
