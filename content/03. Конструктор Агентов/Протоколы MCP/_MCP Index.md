# 🔌 MCP Index: Model Context Protocol

> [!abstract] Роль в системе
> **MCP** — это универсальный стандарт связи между ИИ-моделью и внешними данными/инструментами. Если промпты — это мысли, то MCP-серверы — это органы чувств и конечности твоего ИИ.

---

## 🛠 Установленные серверы

Ниже приведен список активных интеграций, доступных твоим агентам через `mcp_config.json`.

### 📂 Системные и Файловые
- [[Filesystem MCP]] — **База.** Чтение и запись файлов в твоем Vault. Без него ИИ "слеп" к твоим заметкам.
- [[Sequential Thinking MCP]] — **Логика.** Позволяет модели строить сложные многошаговые цепочки рассуждений, не теряя нить мысли.

### 🌐 Поиск и Веб-серфинг
- [[Brave Search MCP]] — **Глаза в сети.** Быстрый поиск актуальной информации, новостей и документации в реальном времени.
- [[Puppeteer MCP]] — **Глубокое погружение.** Полноценный браузер под управлением ИИ для парсинга сайтов со сложным JS и обхода ограничений.

### 🧠 Память и Расписание
- [[Memory MCP]] — **Цифровой гиппокамп.** Позволяет ИИ запоминать факты о тебе и твоих проектах вне контекстного окна чата.
- [[Google Calendar MCP]] — **Руки в реальности.** Управление временем, создание встреч и синхронизация задач с календарем.

## 🗺 Карта расширения (Roadmap)
*Рекомендованные серверы для следующей волны установки из "Топ-30":*

1. **Python Interpreter** — для запуска кода и математических вычислений прямо в базе.
2. **YouTube Transcript** — для мгновенного конспектирования видео лекций.
3. **GitHub MCP** — для прямой работы с репозиториями кода.

---

## ⚙️ Управление конфигурацией

Все эти серверы активируются в главном файле настроек:
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

> [!warning] Важно
> При добавлении нового сервера всегда проверяй его работоспособность через команду `/mcp` в консоли или через индикатор подключения в Cursor.
