## Порядок проектирования

1. Начни с одного model call или детерминированного workflow.
2. Опиши состояние, инструменты, права, ошибки и критерий завершения.
3. Добавь agent loop только при необходимости динамически выбирать следующее действие.
4. Выбери framework после архитектуры, а не до неё.
5. Проверь качество через evals и трассировку реальных траекторий.
