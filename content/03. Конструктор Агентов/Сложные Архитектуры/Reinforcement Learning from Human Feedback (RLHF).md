# RLHF (Reinforcement Learning from Human Feedback)

> [!abstract] Суть
> RLHF — семейство методов, в которых человеческие предпочтения используются для построения сигнала вознаграждения, а затем политика модели оптимизируется методами обучения с подкреплением.

## Классический конвейер

1. **SFT:** модель обучают на примерах желаемых ответов.
2. **Preference data:** люди сравнивают несколько ответов.
3. **Reward model:** отдельная модель учится предсказывать эти предпочтения.
4. **RL optimization:** языковую модель оптимизируют по награде, например с помощью PPO, удерживая её близко к исходной политике.

SFT подготавливает instruct-модель, но сам по себе не является RLHF. DPO использует preference data без отдельного явного reward model и без классического RL-цикла, поэтому его лучше рассматривать отдельно.

## Что RLHF может улучшать

- следование инструкциям;
- полезность и стиль;
- отказ от части опасных запросов;
- соответствие предпочтениям выбранной группы оценщиков.

## Ограничения

- предпочтения оценщиков не равны объективной истине;
- reward model можно эксплуатировать;
- модель может стать многословной, соглашательской или чрезмерно осторожной;
- RLHF не гарантирует честность, фактическую точность или безопасность;
- поведение конкретной модели нельзя надёжно вывести только из названия метода обучения.

Constitutional AI, RLAIF, DPO и другие методы связаны с alignment, но не являются синонимами RLHF.
