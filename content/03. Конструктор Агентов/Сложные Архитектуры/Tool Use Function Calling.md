# Tool Use (Function Calling)

> [!abstract] Суть
> **Tool use / function calling** — механизм, при котором модель формирует структурированное предложение вызвать один из описанных инструментов. Приложение валидирует аргументы, решает, разрешён ли вызов, выполняет его и возвращает наблюдение модели.

---

## ⚙️ Как работает «Петля инструмента»

Типовой процесс состоит из четырёх этапов:

1. **Распознавание:** Модель видит запрос, требующий точных данных (напр., *"Сколько слов в моей папке 'Inbox'?"*).
2. **Вызов (Call):** Вместо текста модель выдает команду: `count_words(folder="Inbox")`.
3. **Исполнение:** Система (твой компьютер или сервер) выполняет код и возвращает результат (напр., `{"total_words": 15420}`).
4. **Интерпретация:** Модель получает эти данные и пишет человеческий ответ: *"В папке 'Inbox' сейчас 15 420 слов"*.



---

## 🛠 Примеры инструментов

| Инструмент | Зачем это нужно | Пример запроса |
| :--- | :--- | :--- |
| **Calculator** | Математическая точность. | $2^{10} \times 1.5$ |
| **Google Search** | Актуальные данные из сети. | "Курс BTC на сегодня" |
| **Python Interpreter** | Сложные вычисления или графики. | "Построй график роста моих заметок" |
| **API заметок** | Манипуляция файлами. | "Создай новую заметку в папке Daily" |

## 🚀 Tool Use в экосистеме заметок

Поддержка зависит от продукта и выбранной модели. В приложениях для заметок инструменты могут применяться так:

* **Smart Connections:** Использует инструменты для поиска (Retrieval) самых релевантных кусков текста в твоей базе.
* **Text Generator (Custom Tools):** Позволяет создавать свои скрипты на JS, которые модель может вызывать для обработки текста.
* **Local Python Scripts:** Ты можешь написать скрипт, который LLM будет использовать как «калькулятор» для анализа твоих данных в формате Markdown.

---

## 💡 Почему это важно?
Инструменты дают доступ к вычислениям и свежим данным, но модель может выбрать не тот инструмент или передать неверные аргументы. Поэтому схемы, проверка прав, таймауты, журналирование и валидация результата остаются обязанностью приложения.
