# Быстрый старт Codex

> [!abstract] Суть
> Codex — coding-agent OpenAI с CLI, IDE, desktop и cloud-интерфейсами. CLI работает с локальным проектом: читает файлы, предлагает или применяет изменения и запускает доступные команды в рамках выбранных permissions.

## Установка и вход

Для macOS/Linux официальный standalone installer:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

После установки:

```bash
cd /path/to/project
codex
```

При первом запуске можно войти через ChatGPT. Доступен и вход с API key, но биллинг и часть возможностей тогда определяются настройками API-организации. Актуальные варианты всегда проверяй в официальной документации.

## Первый сеанс

1. Проверь рабочую папку и `git status`.
2. Попроси Codex описать структуру и активные инструкции.
3. Задай небольшое изменение и критерий готовности.
4. Проверь показанные команды, diff и результаты тестов.
5. Перед commit убедись, что staged только нужные файлы.

## Полезные команды

| Команда | Назначение |
| :--- | :--- |
| `/status` | Текущая конфигурация сеанса |
| `/permissions` | Границы редактирования и запуска команд |
| `/model` | Модель и reasoning effort |
| `/review` | Review изменений без их исправления |
| `/init` | Создать стартовый `AGENTS.md` |
| `codex resume` | Продолжить сохранённый сеанс |

Сверяй полный список с интерфейсом и `codex --help`: продукт меняется быстро.

## `AGENTS.md`

В проектном `AGENTS.md` держи устойчивые правила: команды build/test, структуру, соглашения и критерии review. Инструкции могут быть вложенными; файл ближе к рабочей папке имеет более узкую область. Не превращай его в энциклопедию — повторяющийся feedback полезнее случайных пожеланий.

## Права и секреты

- начинай с минимальных permissions и расширяй их под конкретную задачу;
- не коммить `.codex/auth.json`, `.env` и другие credentials;
- доступ к записи не равен разрешению на push, публикацию или внешнее сообщение;
- review от того же агента дополняет, но не заменяет тесты и человеческую проверку риска.
