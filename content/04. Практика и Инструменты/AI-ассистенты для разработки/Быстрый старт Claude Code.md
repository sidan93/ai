# Быстрый старт Claude Code

> [!abstract] Суть
> Claude Code — coding-agent Anthropic, доступный через CLI, IDE, desktop и web. CLI читает проект, меняет файлы и запускает команды в пределах выбранного permission mode.

Если пока неясно, чем разговор с Claude отличается от Cowork и Claude Code, начни с [[claude|обзора Claude]]. Здесь — установка и первый сеанс Claude Code CLI.

## Установка и вход

Для macOS/Linux/WSL официальный native installer:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Native install — текущий рекомендуемый путь и обновляется автоматически. Также документированы Homebrew, WinGet и системные пакеты; старый глобальный npm-вариант больше не стоит показывать как основной.

Запуск:

```bash
cd /path/to/project
claude
```

Войти можно через подходящий план Claude, Anthropic Console либо поддерживаемого enterprise provider. Не сохраняй credentials в проекте.

## Первый сеанс

1. Проверь рабочую папку и `git status`.
2. Сначала попроси объяснить проект без правок.
3. Дай небольшую задачу и критерий готовности.
4. Проверь proposed changes, diff и запущенные команды.
5. Подтверди только понятные действия и самостоятельно оцени тесты.

## Команды и продолжение работы

`/help` внутри установленной версии — источник истины. Для повседневной работы особенно полезны `/resume`, `/clear`, permission modes и просмотр diff; их точный набор меняется.

## `CLAUDE.md`

Храни в нём назначение проекта, ключевые директории, команды проверки, соглашения и границы. Claude Code также поддерживает skills, hooks, MCP и subagents; добавляй их под повторяемую потребность, а не «на всякий случай».

## Права

- permission mode определяет, когда инструмент спрашивает подтверждение;
- deny rules помогают закрыть секреты и защищённые пути;
- дополнительные директории расширяют доступ к файлам, но не обязательно становятся корнями всей конфигурации;
- право выполнить shell-команду требует той же осторожности, что ручной терминал.

## Блокировки, лимиты и проблемы доступа

Правила доступа в этом разделе проверены **17 ноября 2026 года**. Это не означает повторной проверки всех команд старой инструкции. Главное: **«Claude Code перестал работать» ещё не означает бан аккаунта**. Сначала прочитай точное сообщение, а не подбирай способ сменить аккаунт или сеть.

### Как отличить одну проблему от другой

| Что видно | Что это может означать | Первый шаг |
| :--- | :--- | :--- |
| Сообщение о достигнутом лимите с временем сброса | Исчерпана доступная квота | Проверить лимит и время восстановления в своём аккаунте |
| Заполнен context window | Слишком длинная история текущей сессии, не блокировка аккаунта | Сохранить важное; продолжить через `/compact` или начать новую задачу через `/clear` |
| API `401` | Проблема аутентификации; нужно прочитать подробности ошибки | Проверить выбранный способ входа и действительность credentials |
| API `403 permission_error` | Нет прав на конкретный ресурс | Проверить организацию, workspace и доступ к ресурсу |
| API `429 rate_limit_error` | Ограничение скорости, уровня расходов либо workspace | Прочитать причину и проверить соответствующий лимит |
| API `529 overloaded_error` | Временная перегрузка сервиса | Проверить статус и повторить позже |
| Явное уведомление о suspension/ban или restricted account | Ограничен аккаунт либо организация | Перейти к официальному пересмотру решения |

Коды выше относятся к **Claude API**, а не ко всем страницам браузера и сетевым посредникам. Сам по себе `403` не устанавливает причину блокировки. `/clear` удаляет историю сессии и не отменяет квоту или бан; перед ним сохрани нужный контекст. [Ошибки API](https://platform.claude.com/docs/en/api/errors) · [Контекст и лимиты Claude Code](https://support.claude.com/en/articles/14552983-models-usage-and-limits-in-claude-code).

### За что могут ограничить доступ

Anthropic перечисляет среди оснований повторные нарушения Usage Policy, создание аккаунта из неподдерживаемого региона и нарушения условий сервиса. Из этого нельзя вывести универсальную формулу антифрода: «N запросов», конкретный VPN или определённый паспорт не подтверждены как автоматический триггер для каждого аккаунта. Сообщение другого пользователя тоже не устанавливает причину твоего случая. [Официальные основания и апелляции](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals).

**Подписка и API не взаимозаменяемы.** OAuth-вход подписчика предназначен для обычной работы в Claude Code и других собственных приложениях Anthropic. Для продуктов и сервисов, использующих возможности Claude, в том числе через Agent SDK, документация направляет разработчиков к API key или поддерживаемому cloud provider. Стороннему разработчику нельзя предлагать вход Claude.ai внутри своего приложения, собирать session tokens или обслуживать пользователей через их потребительские подписки.

Но это **не запрет любой внешней инфраструктуры**: правила отдельно допускают вход пользователя со своей подпиской в немодифицированный Claude Code, размещённый платформой, при соблюдении перечисленных коммерческих условий. Поэтому оценивай не только название оболочки, но и способ авторизации, кто получает credentials и на чей договор приходится использование. [Authentication and credential use](https://code.claude.com/docs/en/legal-and-compliance).

### Россия, поездки и VPN

В Supported Regions Policy, действующей с **12 ноября 2026 года**, России нет среди поддерживаемых регионов. Политика охватывает Claude Code, приложения, API и модели через облачные платформы и авторизованных реселлеров. Учитывается физическое местонахождение человека; для организаций есть также ограничения по регистрации, штаб-квартире и владению или контролю.

Практический вывод: **смена IP через VPN не меняет фактическое местонахождение и не создаёт права доступа**. Обратный вывод «любой VPN обязательно ведёт к бану» из этого не следует. Перед поездкой проверяй условия страны назначения; API и зарубежный посредник не стоит считать автоматическим исключением из региональных правил. [Supported Regions Policy](https://www.anthropic.com/legal/supported-regions).

### Проверка личности и действия при блокировке

Запрос **identity verification** сам по себе ещё не означает бан. Anthropic описывает проверки через Persona для отдельных возможностей и проверок целостности платформы; могут потребоваться физический документ и live selfie. Не передавай документы «помощникам по разблокировке»: открывай процедуру из официального аккаунта. Если проверка не удалась, используй предусмотренные попытки и форму помощи из [официальной инструкции](https://support.claude.com/en/articles/14328960-identity-verification-on-claude). Она отдельно описывает апелляцию при блокировке после проверки, но не гарантирует восстановление.

Если доступ пропал:

1. Сохрани точный текст ошибки, время, способ входа и request ID, если он указан. Удали секреты из скриншотов и логов.
2. Проверь [статус Claude](https://status.claude.com/), затем свой аккаунт, организацию и лимиты. Переустановка CLI не исправляет серверную блокировку.
3. При бане войди в затронутый аккаунт на Claude.ai и открой форму appeal из [страницы апелляций](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals). Для организации со статусом on hold предусмотрен «Request a review». Не рассчитывай на фиксированный срок или положительный исход.
4. Если не работает сама процедура обращения, воспользуйся [инструкцией поддержки](https://support.claude.com/en/articles/9015913-how-to-get-support), описав именно этот сбой.

> [!example] Иллюстрация, не проверено запуском
> CLI остановился с `429`, но аккаунт открывается. Сначала проверяем текст ошибки и лимит: апелляция на бан здесь преждевременна. При явном suspension действуем через пересмотр, а не перебираем настройки терминала.

**Резерв рабочего процесса:** держи изменения в Git, важные решения и незавершённые шаги в файлах проекта. Не оставляй единственный экземпляр результата только в облачной сессии. Это не защищает аккаунт от ограничений, но позволяет продолжить работу независимо от доступности конкретного сервиса.
