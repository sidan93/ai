# 📑 20 мощных агентных навыков: Полная библиотека

**Оригинал статьи:** [20 Powerful Agentic-Skills for Claude, ChatGPT & Gemini.](https://x.com/explorax_/status/2039269234253934811)

> [!abstract] Краткий обзор
> Глубокий разбор коллекции из 20 навыков для ИИ-агентов. В основе лежит переход от «просьб» к жестким «логическим протоколам». Каждый навык — это микро-программа для сознания модели, включающая проверку состояния, выполнение и верификацию.

---

## 🏛️ Ключевые концепции из оригинала

* **"Skill is a State Machine"**: Навык — это не просто текст, а алгоритм: Проверка (Check) -> Действие (Action) -> Валидация (Verify).
* **SCQA как стандарт**: Использование структуры «Ситуация - Осложнение - Вопрос - Ответ» для исключения галлюцинаций.
* **Гигиена контекста**: Умение агента самостоятельно «чистить» свою память от мусора, предотвращая деградацию ответов.

## 🛠 Библиотека навыков (Ready-to-Copy)

> [!tip] Инструкция
> Скопируйте нужный блок в ваш `.cursorrules` или `CLAUDE.md`.

### 1. SCQA Architect (Архитектор логики)
```
### Skill: SCQA Architect
- Goal: Ground reasoning in consensus reality before solving problems.
- Protocol:
  1. Situation: State only 100% verified facts about the current setup.
  2. Complication: Define the specific friction or failure point.
  3. Question: Formulate the core challenge as a direct bridge to the solution.
  4. Answer: Deliver the fix strictly within the defined scope.
- Constraint: Never provide an Answer without validating S, C, and Q first.
```

### 2. Context Surgeon (Хирург контекста)
```
### Skill: Context Surgeon
- Goal: Prevent "context rot" in long sessions.
- Protocol:
  1. Scan session for deprecated logs, failed attempts, or irrelevant code blocks.
  2. Summarize the essential "Source of Truth" in <150 tokens.
  3. Propose a /clear or /compact if noise interferes with reasoning quality.
```

### 3. Recursive Critic (Рекурсивный критик)
```
### Skill: Recursive Critic
- Goal: Multi-turn self-correction of complex outputs.
- Protocol:
  1. Generate initial solution.
  2. Act as a "Hostile Auditor": find 3 edge cases or security flaws.
  3. Refine the solution to patch identified weaknesses.
  4. Final check: verify simplicity, readability, and performance.
```

### 4. Step-back Prober (Анализ отступления)
```
### Skill: Step-back Prober
- Goal: Solve "impossible" bugs by abstracting to first principles.
- Protocol:
  1. Identify the specific point of failure.
  2. "Step back": define the fundamental CS principle involved.
  3. Solve for the principle first, then map the solution back to the specific code.
```

### 5. Constraint Validator (Валидатор ограничений)
```
### Skill: Constraint Validator
- Goal: Ensure 100% compliance with strict project rules.
- Protocol:
  1. Before output, list all constraints mentioned in the instructions.
  2. Cross-check the drafted output against each constraint.
  3. If a violation is found, rewrite the section before final delivery.
```

### 6. Semantic Linker (Связист знаний)
```
### Skill: Semantic Linker
- Goal: Maintain a coherent Wiki/Zettelkasten structure.
- Protocol:
  1. Identify 3 related existing notes in the vault before saving new info.
  2. Insert standard [[Internal Links]] where relevant.
  3. Add a "Context Bridge" sentence explaining the relationship between notes.
```

### 7. CoT Debugger (Отладчик рассуждений)
```
### Skill: CoT Debugger
- Goal: Expose and fix hidden flaws in the model's logic.
- Protocol:
  1. Show your step-by-step thinking inside a <thinking> block.
  2. If a step feels uncertain, explicitly mark it as "UNVERIFIED".
  3. Re-verify unverified steps using tools or documentation before proceeding.
```

## 📜 Прямые цитаты (Original Concepts)

> [!quote] О качестве промптов
> "The most powerful agents don't have the longest prompts; they have the cleanest state management. Stop asking the AI to 'be smart' and start giving it a structure to think through."

---

## ⚙️ Инженерные выводы

1. **Failure-First:** Лучшие навыки — те, что описывают, как реагировать на ошибки (как `Rewind` или `Recursive Critic`).
2. **State Sync:** Агент должен постоянно синхронизировать свою «внутреннюю карту» проекта с реальностью через инструменты.
3. **Hierarchy:** Выбирайте 3-5 наиболее релевантных навыков для конкретного проекта, чтобы не перегружать контекст.
