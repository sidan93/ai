# LM Studio

> [!abstract] Определение
> **LM Studio** — это кросс-платформенное приложение (GUI), предназначенное для поиска, загрузки и запуска локальных LLM. Оно превращает сложный процесс настройки окружения в интуитивно понятный интерфейс "в один клик".

---

## ✨ Ключевые возможности

1. **Интеграция с Hugging Face:** Позволяет искать и скачивать модели напрямую в приложении, фильтруя их по популярности и совместимости.
2. **Детектор совместимости:** Приложение анализирует твою [[Локальное железо для AI|VRAM]] и помечает модели (и конкретные [[Форматы и Квантование (Quantization)|кванты]]), которые гарантированно запустятся на твоём железе.
3. **Локальный сервер (OpenAI-API):** Одной кнопкой запускает локальный HTTP-сервер, который полностью имитирует API OpenAI.
4. **Песочница (Playground):** Удобный чат для тестирования разных моделей с настройкой [[Temperature]], системных промптов и параметров контекста без правки кода.

---

## 🚀 Почему это важно на практике?

LM Studio — это идеальный "бэкенд" для твоей базы знаний:

* **Мостик к плагинам:** Многие продвинутые ИИ-плагины (напр., *Copilot*, *Text Generator*, *Smart Connections*) умеют работать через "Custom API". Ты запускаешь сервер в LM Studio, копируешь адрес (обычно `http://localhost:1234/v1`) и твое рабочее пространство получает "мозги" GPT-4, но работающие полностью приватно.
* **Визуальный контроль:** В отличие от консольных решений, здесь ты видишь нагрузку на видеокарту и скорость генерации в реальном времени.

## 📋 LM Studio vs Ollama

| Характеристика | LM Studio | [[Ollama]] |
| :--- | :--- | :--- |
| **Интерфейс** | Графический (GUI) | Консольный (CLI) |
| **Выбор кванта** | Можно выбрать любой файл вручную | Автоматический выбор разработчиками |
| **Наглядность** | Видны логи и параметры генерации | Работает как тихая служба |
| **Для кого** | Для тех, кто хочет видеть всё и сразу | Для любителей автоматизации и минимализма |

---

## 💡 Совет по настройке
При запуске сервера в LM Studio обязательно включи параметр **"GPU Offload"** и выкрути его на максимум, если у тебя есть дискретная видеокарта. Это перенесет вычисления с медленного процессора на быструю видеопамять.
