# LM Studio

> [!abstract] Суть
> LM Studio — настольное приложение для поиска, скачивания, тестирования и локального запуска моделей. Оно сочетает графический интерфейс, управление моделями и локальный API-сервер.

## Когда выбирать

- хочется видеть параметры загрузки и использование памяти;
- нужно сравнивать несколько моделей и квантов;
- требуется OpenAI- или Anthropic-совместимый локальный endpoint;
- нужен графический интерфейс без отдельного web UI.

## Основные возможности

- поиск совместимых моделей и квантов;
- чат и сравнение конфигураций;
- GPU offload и настройка контекста;
- локальный сервер, обычно на `http://localhost:1234/v1`;
- работа с GGUF и поддерживаемыми MLX-моделями;
- Bionic для агентных сценариев.

Совместимый API воспроизводит форму популярных API, но не гарантирует поддержку всех моделей, параметров и инструментов оригинального облачного сервиса.

## Приватность

При локальном инференсе содержимое запросов не нужно отправлять поставщику модели. Но отдельно проверь:

- не выбрана ли облачная модель;
- включена ли телеметрия;
- используют ли плагины внешние embeddings или поиск;
- нет ли облачного fallback;
- какие данные сохраняются в истории приложения.

## Настройка без магии

1. Выбери модель по размеру файла и лицензии.
2. Оставь запас памяти под KV-cache.
3. Начни с умеренного контекста.
4. Увеличивай GPU offload, пока конфигурация остаётся стабильной.
5. Измеряй скорость после прогрева и на одинаковых запросах.
