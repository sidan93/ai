# Железо для локальных моделей

> [!abstract] Главное правило
> Для инференса важны объём доступной памяти, пропускная способность памяти и размер конкретного файла модели. Число активных параметров MoE не равно объёму памяти, необходимому для хранения всех весов.

## Из чего складывается память

- **Веса модели:** основной объём; зависит от общего числа параметров и кванта.
- **KV-cache:** растёт с длиной контекста, batch size и архитектурой модели.
- **Runtime и буферы:** движку тоже нужен запас.
- **Другие приложения:** особенно важно для unified memory на Mac.

Грубая оценка весов до служебных накладных расходов:

| Точность | Примерный объём на 1B параметров |
| :--- | :--- |
| FP16/BF16 | около 2 GB |
| 8-bit | около 1 GB |
| 4-bit | около 0,5–0,7 GB |
| 2–3 bit | меньше, но потеря качества обычно заметнее |

Фактический файл может отличаться из-за метаданных, смешанной точности и схемы квантования.

## Ориентиры по доступной памяти

| Память | Разумный старт |
| :--- | :--- |
| 8 GB | 3B–8B, 4-bit, небольшой или средний контекст |
| 16 GB | 7B–14B, 4-bit |
| 24 GB | 14B–32B, 4-bit; иногда больше с частичным offload |
| 32–64 GB | 20B–70B в подходящем кванте, если помещаются веса и KV-cache |
| 80 GB+ | крупные модели и серверные сценарии |

Это ориентиры, а не гарантия скорости или качества.

## NVIDIA

- CUDA обычно даёт наиболее широкую поддержку высокопроизводительных inference-библиотек.
- Полная загрузка в VRAM обычно быстрее CPU/RAM offload.
- Multi-GPU может объединять память для модели, но добавляет стоимость обмена между устройствами.
- Покупать карту только по названию поколения не стоит: сначала смотри VRAM, bandwidth, энергопотребление и поддержку runtime.

## Apple Silicon

На Apple Silicon CPU и GPU используют unified memory. Это позволяет запускать модели, которые не помещаются в VRAM обычной потребительской карты, но доступная память также нужна системе и приложениям.

Скорость зависит от поколения чипа, пропускной способности памяти, runtime, кванта и контекста. Сравнивай бенчмарки только на близкой конфигурации.

## Перед скачиванием модели

1. Посмотри размер конкретного файла GGUF/MLX/EXL2.
2. Оставь запас памяти под KV-cache и runtime.
3. Проверь поддержку архитектуры выбранным движком.
4. Найди бенчмарк на похожем железе.
5. Начни с небольшого контекста и увеличивай его по необходимости.
