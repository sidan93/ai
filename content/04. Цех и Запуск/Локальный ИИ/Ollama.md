# Ollama

> [!abstract] Суть
> Ollama — локальный runtime и менеджер моделей. Он скачивает совместимые сборки, запускает их и предоставляет CLI и HTTP API.

## Когда выбирать

- нужен простой локальный API;
- хочется запускать модели одной командой;
- требуется backend для другого интерфейса или инструмента;
- важна работа на macOS, Linux или Windows без ручной сборки inference-стека.

## Основные команды

| Команда | Что делает |
| :--- | :--- |
| `ollama run <model>` | Скачать при необходимости и запустить модель |
| `ollama pull <model>` | Скачать или обновить модель |
| `ollama list` | Показать установленные модели |
| `ollama ps` | Показать загруженные модели |
| `ollama stop <model>` | Выгрузить модель |
| `ollama serve` | Запустить сервер вручную |

Точное имя и размер модели проверяй в [Ollama Library](https://ollama.com/library). Не копируй команду со случайным тегом, пока не убедишься, что он существует и помещается в память.

## API

Локальный сервер обычно доступен по адресу `http://localhost:11434`. Ollama предоставляет собственный API и совместимые интерфейсы для ряда инструментов. Совместимость не означает поддержку каждой возможности оригинального провайдера.

## Важные ограничения

- Заявленное контекстное окно модели не означает, что его разумно выставлять полностью.
- Большая MoE-модель хранит все свои веса, даже если на токен активируется только часть экспертов.
- Локальный runtime не делает всю цепочку автоматически приватной: проверь UI, плагины, веб-инструменты и fallback.
- Качество tool calling зависит и от модели, и от шаблона, и от клиента.
